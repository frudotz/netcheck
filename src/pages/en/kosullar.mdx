# Terms of Use

This application is an **educational project** developed for the **İstinye University Vocational School MYO063 Mobile Programming** course. It is not a commercial product and makes no service commitment.

## 1. Scope
NetCheck shows local network information and runs basic connectivity tests against fixed targets (gateway, `1.1.1.1`, `8.8.8.8`, `cloudflare.com`). The Connection Score is a simple evaluation, not a professional network measurement.

## 2. User responsibilities
- Run the application only on networks you are authorized to use.
- When sharing reports, keep in mind that they include network details such as IP addresses.
- Results are informational; seek expert help for critical decisions.
