# About NetCheck

**NetCheck — Local Network Diagnostics and Connection Analysis.** It shows the basic details of the network you are connected to, runs a few simple connectivity tests and turns the results into a diagnostic report with a unique ID generated in Rust (`NCHK-YYYY-XXXXXXXX`).

## Purpose and story

"No internet" problems are often hard to place: is it the router, DNS or the outside connection? NetCheck separates these layers on a single screen and prepares an ID-numbered report you can share with technical support. There is no server, account or cloud sync; everything stays on your device.

## Technologies

- **Tauri v2** — desktop runtime and the Rust ↔ UI bridge (IPC)
- **Rust** — network information, ping, DNS and HTTPS tests, report ID
- **Astro** — static site build and file-based routing
- **Svelte 5** — screens and state management (`$state`, `$derived`)
- **React 19 + MDX** — these information pages and the interactive badge

## Platform status

NetCheck runs as a verified **Windows** desktop application. The **Android** build has been verified on the Android emulator (Android 16); it has not yet been tested on a physical device. macOS and Linux code compiles and passes tests in CI but has not been run as an app. iOS is a planned target platform.
